# Student Management System

A console-based Student Management System built using core Python. This application helps users manage student records by adding, viewing, searching, updating, and deleting student details.

## Features

- Add new student records
- View all student records
- Search students by ID
- Update student information
- Delete student records
- Store data using JSON file handling
- Exception handling for invalid user input

## Technologies Used

- Python
- Object-Oriented Programming
- File Handling
- JSON
- Exception Handling

## How to Run

```bash
python student_management.py
```

The application will create a `students.json` file to store student records.
